1. About Recora

Recora is a Chrome browser extension that records browser tab audio and microphone input during meetings, automatically transcribes the audio using AI speech-to-text services, generates meeting summaries and minutes, and syncs data securely to your personal cloud storage. Recora is intended for personal and professional productivity use only.

3. Audio Data & AI Training Important

3.1 How Your Audio Is Processed

When you stop a recording, Recora:

  1. Stores the raw audio file (WebM format) in your private Azure Blob Storage container, protected by your account credentials.
  2. Sends the audio to Deepgram (a third-party AI transcription service) for speech-to-text conversion. This transmission is proxied through Recora's secure backend server to protect API keys.
  3. Generates a summary, key points, decisions, and action items from the transcript using pattern-matching algorithms running locally within the extension.

3.2 AI Training Disclosure Required Reading

🔔 Your audio and transcript data may be used by third-party AI service providers (including Deepgram) to improve and train their AI models, subject to their own privacy policies and terms of service. Recora does not control how third-party services handle data once it is transmitted to them.

By using Recora, you acknowledge and consent to the possibility that:

  • Audio files transmitted to Deepgram for transcription may be retained by Deepgram and used to train or improve AI speech recognition models.
  • Transcript text generated by AI models may be subject to Deepgram's data retention policies.
  • Recora's backend may log metadata (timestamps, file sizes, user identifiers) for operational and debugging purposes.

We strongly recommend reviewing Deepgram's Privacy Policy and Terms of Service before using Recora.

4. Data Storage & Security Info

4.1 Where Your Data Is Stored

  • Audio files: Stored in Microsoft Azure Blob Storage, in a container scoped to your Google account ID. Access is controlled via time-limited Shared Access Signature (SAS) tokens generated by Recora's backend.
  • Recording metadata & transcripts: Stored locally in your browser's chrome.storage.local and synced as a JSON file to your Azure storage container.
  • Calendar data: Fetched directly from Google Calendar API using your OAuth token. Calendar events are not stored on Recora servers.

4.2 Data Retention

Recora retains your data in Azure as long as your account remains active. You may delete individual recordings at any time from within the extension. Deleting a recording removes the local record; the audio file in Azure must be manually deleted via the Azure Portal if desired.

4.3 Security Measures

  • All communication between the extension and Recora's backend uses HTTPS (TLS 1.2+).
  • Your Google OAuth access token is verified server-side on every request using Google's token validation endpoint.
  • API keys (Deepgram, Azure) are never exposed to the client — they are stored exclusively on the backend server.
  • Azure storage access is granted via short-lived SAS tokens scoped to your user ID only.
  • Recora's backend enforces CORS restrictions and rate limiting to prevent abuse.

4.4 Security Breach Notification

In the event of a data breach that affects your personal information, Recora will make reasonable efforts to notify affected users within 72 hours of becoming aware of the breach, subject to applicable law.

5. Google Account & OAuth

Recora requests the following Google OAuth scopes:

  • openid, profile, email — to identify you and personalise the experience.
